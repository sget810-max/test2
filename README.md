# 路線図メーカー

架空の鉄道路線図をブラウザ上で作成できるWebアプリです。ビルド不要・依存ライブラリなしで、`index.html` を開くだけで動きます。

## 主な機能

- **駅の配置**: ダブルクリック（ダブルタップ）で駅を追加。駅・ランドマーク・地形はすべてグリッドに沿って配置。
- **閲覧モード**（「👁 閲覧」/ B キー）: 編集せずに地図を見るモード。駅・路線・ランドマークをタップすると情報カード（乗り入れ路線・乗り換え・停車駅一覧など）を表示し、路線を選ぶとその路線だけを強調。
- **路線の作成**: 駅を順にクリックして路線を延長。線をタップして駅間を選び、ダブルクリックした場所を通るようにその駅間の線路を曲げる（駅は作らない）、Shift+クリックで起点側に追加、始発駅をクリックすると環状線に。
- **路線図らしい描画**: 区間は 0°/45°/90° の8方向で自動的に折れ曲がり、角は丸く描画。区間をクリックして、右の欄で 折れ線（2通り）／直線／曲線 を切り替え。
- **経路の自由な変更**: 路線ツールで線をタップして駅間を選び、ダブルタップ（または線をドラッグ）すると経由点ができ、経路を好きな形に曲げられます（経由点はドラッグで移動、ダブルタップで削除）。路線ごとに「全区間を曲線に」「経由点をリセット」も可能。
- **ターミナル駅**: 駅を選んで「🚉 ターミナル」を押すと二重丸の駅に（それ以外は普通の駅と同じ）。
- **乗り換え駅**: 離れた駅どうしを連絡通路でつないで乗り換え駅に設定（駅の欄の「＋ 乗り換え駅を追加」→ 相手の駅をタップ、または2駅を選んで「この2駅を乗り換え駅にする」）。
- **並走表示**: 同じ区間を複数の路線が通ると自動的に並べて描画。乗換駅はカプセル型の記号に。
- **駅名ラベル**: 自動配置、または8方向から手動で指定。副駅名（英字・読み）も表示可能。
- **路線の編集**: 路線名・記号・ラインカラー・太さ・環状線、駅順の並べ替え・反転。
- **ダブルクリック／ダブルタップで駅を追加**（路線ツール以外）: 地図をダブルタップすると駅が置け、すぐに駅名を入力できます。路線の上なら区間に挿入。駅をダブルタップすると駅名をその場で編集。
- **範囲選択**: 背景ドラッグ（スマホは「範囲」ツール）や Shift+クリックで複数の駅を選択し、まとめて移動・整列（横一列／縦一列／等間隔）・駅名位置の一括変更・削除・新しい路線の作成ができます。
- **駅の統合**: 駅をドラッグして別の駅に重ねると、1つの乗換駅に統合。
- **駅からの操作**: 「この駅から路線を延長」「新しい路線を始める」、座標の数値入力、矢印キーでの微調整。
- **操作設定**: グリッド間隔（マスの大きさ）、新しい駅の名前、背景ドラッグの動作、追加後すぐ駅名を入力、重ねたら統合 などを切り替え（ブラウザごとに保存）。
- **地形エディター**（左上の地形ロゴ / T キー。路線図ロゴで路線図エディターに戻る）:
  - 地形はすべてグリッドのマス目単位（一度に 1マス／2×2／3×3／5×5 を塗れる）
  - 🌊 水域: タップ・なぞったマスを海・川・湖にする
  - 🟩 陸地: タップ・なぞったマスを陸地に戻す
  - 🏝 島モード: 陸地と水域を入れ替え、何も塗っていない場所を海にする（島・半島づくりに）
  - 📍 ランドマーク: 寺院・神社・タワー・城・山・公園・学校・病院・空港・港など15種類を配置・移動・名前付け
  - 水の色・陸地の色を変更可能。地形も画像書き出しに含まれます
- **スマホ対応**: 2本指で拡大縮小・移動。
- **区間への駅挿入**: 路線の上をダブルクリック。
- **元に戻す／やり直し**、ブラウザへの自動保存。
- **保存・読み込み**: JSON 形式。
- **書き出し**: タイトルと凡例付きの SVG / PNG 画像。

## 使い方

```sh
# そのまま開く
open index.html
# もしくは簡易サーバーで
python3 -m http.server 8000   # → http://localhost:8000
```

GitHub Pages を有効にすれば（Settings → Pages → ブランチを選択）、そのままWebサイトとして公開できます。

## ショートカット

| キー | 動作 |
| --- | --- |
| V / B / R / S / L / D | 選択 / 閲覧 / 範囲 / 駅 / 路線 / 削除 |
| T | 地形エディターの切り替え |
| Enter | 選択中の駅の名前を編集 |
| 矢印キー（+Shift） | 選択中の駅を移動（大きく移動） |
| Ctrl+A | すべての駅を選択 |
| Delete | 選択中の駅・路線を削除 |
| Ctrl+Z / Ctrl+Y | 元に戻す / やり直し |
| Ctrl+S | JSONで保存 |
| F | 全体を表示 |
| Space+ドラッグ, ホイール | 画面移動, 拡大縮小 |
| Esc | 選択解除 |

## ファイル構成

- `index.html` — 画面構成
- `style.css` — スタイル（スマホ表示にも対応）
- `app.js` — エディタ本体（描画・操作・保存・書き出し）
