    使い方

    1. 地図をダブルクリック（ダブルタップ）すると駅を追加できます。路線の上なら、その区間に駅を挿入します。駅をダブルクリックすると駅名をその場で編集できます。
    2. 駅ツールなら1回のクリックで駅を置けます。
    3. 路線ツールで駅を順にクリックすると、選択中の路線が延びます。空白をクリックすると新しい駅を作って延長します。Shift+クリックで起点側に追加、始発駅をクリックすると環状線になります。
    4. 選択ツールで駅をドラッグして移動。別の駅に重ねると1つの乗換駅に統合されます。区間をクリックすると、曲がり方（2通りの折れ方／直線）を選べます。
    5. 範囲選択: 背景をドラッグ（スマホは範囲ツール）で複数の駅を選択。Shift+クリックで追加・解除。まとめて移動・整列・削除・路線化ができます。
    6. ホイールまたは2本指で拡大縮小。右ドラッグ・Space+ドラッグ・タッチ操作で画面移動。

    ショートカット: V 選択 / R 範囲 / S 駅 / L 路線 / D 削除 / Enter 駅名を編集 / 矢印キー 駅を移動（Shiftで大きく）/ Ctrl+A すべての駅を選択 / Delete 削除 / Ctrl+Z 元に戻す。
    作業内容はブラウザに自動保存されます。
